# IDEATHON_2026-Pedal-Que-Move-(Bicicleteiros-Unidos)
 O projeto 'Pedal que Move' tem a intenção de incentivar a mobilização da sociedade de maneira limpa para fins sustentáveis na sociedade, visando também o impacto social positivo dentro do contexto relacionado ao trânsito urbano, com a iniciativa de diminuir o congestionamento de veículos e a deterioração da atmosfera em regiões metropolitanas. O projeto em questão é somente uma prototipagem do que um dia o mesmo pode se tornar. Será apresentado sua proposta, funcionalidades simples e intenção da equipe com o desenvolvimento do projeto.
